### 本轮做了什么

仅阅读已有记录、核对当前源码、组织文档和打包；没有新增模型请求、GPU训练、Docker实验或官方评分。历史验收数字属于当时版本，不当作本轮验收。记录中的根因推断与直接观测分开，未解决问题继续保留。

ZIP解压后包含一个以项目名命名的目录，在其中运行：

```sh
cd ProbeGRPO
python3 docs/incidents/verify_bundle.py
```

校验覆盖选定快照文件的完整性、台账字段及引用路径；不证明历史日志真实性，也不重新验证模型能力。在线仓库与ZIP包含的相同文件可运行同一命令。ZIP里的下载链接指向GitHub交付件，压缩包自身未重复嵌套；历史来源文档里更深层的外部链接仍以原仓库为准。
